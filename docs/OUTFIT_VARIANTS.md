# Outfit variants in Appearance

This sandbox supports outfit variants as plain child folders under an outfit
in **My Outfits**. The parent folder holds items shared by every variant; each
child folder is one selectable variation. A child must be a plain inventory
folder directly under the outfit.

The Appearance preview shows left and right controls when variants are
available. Use **Add outfit variant** in the outfit preview or thumbnail menu
to create one; new variants are named `Variant`, `Variant 2`, and so on. The
selected child supplies the outfit's thumbnail and detailed portrait, and the
selection is remembered in the viewer's settings. Wearing the outfit applies
its direct items together with the selected variant's contents; sibling
variants are excluded. The same behavior applies to base outfits.

When an outfit is expanded in the **Outfits** or **Base outfits** list, its
variants appear beneath it. Select a row to make that variation active, or
drag wearable inventory items onto it to add links to that variation. The
variant folder is also available in Inventory, where it can receive wearable
items through the same outfit-link rules.

This is experimental sandbox behavior and may change as the viewer source
advances.
