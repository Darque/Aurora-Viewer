# Outfit variants in Appearance

This sandbox supports outfit variants as plain child folders under an outfit
in **My Outfits**. The parent folder holds items shared by every variant; each
child folder is one selectable variation. A child must be a plain inventory
folder directly under the outfit.

The Appearance preview shows left and right controls when variants are
available. The selected child supplies the outfit's thumbnail and detailed
portrait, and the selection is remembered in the viewer's settings. Wearing the
outfit applies its direct items together with the selected variant's contents;
sibling variants are excluded. The same behavior applies to base outfits.

Variants can be created or managed through the normal Inventory folder
controls. This is experimental sandbox behavior and may change as the viewer
source advances.
